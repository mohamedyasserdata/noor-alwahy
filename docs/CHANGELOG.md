# سجل التغييرات

## 2026-10-18

### أضيف

- P0-T07: مكتبة `lib/time` موحدة على Luxon لتحويل wall-clock + IANA إلى UTC والعكس.
- سياسة DST صريحة ترفض الأوقات غير الموجودة والغامضة افتراضيًا، وتتيح `earlier`/`later`
  للحالة المكررة فقط.
- اختبارات وحدة لانتقالي القاهرة في 2026، وثبات الرياض ودبي حول التاريخين نفسيهما.
- ADR-007 يوثق حدود الإدخال ومصدر tzdata وبقاء قرار `anchor_timezone` لدى المالك.

## 2026-10-17

### أضيف

- P0-T01: مشروع Next.js/React/TypeScript صارم مع pnpm وESLint وPrettier وHusky.
- P0-T02: رموز ألوان الهوية، الخطوط العربية المحلية، مكوّنات UI الأساسية، وصفحة `/dev/ui`.
- P0-T03: next-intl 4.14.9، مسارات `/ar` و`/en`، و`lang/dir` ديناميكيان، ورسائل منفصلة،
  ومبدّل لغة يحفظ المسار وكل قيم query.
- `proxy.ts` متوافق مع Next.js 16 ويجمع توجيه next-intl مع تحديث جلسة Supabase.
- حارس `check-logical-css` داخل lint لمنع utilities وخصائص الاتجاه الفيزيائية.
- أيقونة تطبيق محلية، ورابط تخطٍ للمحتوى، ودعم تقليل الحركة في العناصر المتحركة.
- سجل تقدم دائم وقرارات ADR للإصدارات ونظام التصميم.
- Supabase CLI وإعداد محلي، وعملاء browser/server/admin، وملف `.env.example`، وسكربت
  توليد أنواع يحافظ على الملف السابق عند الفشل.
- أنواع قاعدة البيانات المولّدة فعليًا من PostgreSQL المحلي، وصفحة تحقق داخلية ثنائية اللغة في
  `/[locale]/dev/supabase` تنفذ استعلام Server Component حقيقيًا على Data API.
- `supabase/seed.sql` فارغ مقصودًا حتى تضيف كل مهمة بياناتها التجريبية مع مخططها المالك.
- بوابة GitHub Actions مقسمة إلى فحص التطبيق وفحص الأسرار، مع تثبيت إصدارات Node وpnpm
  وإجراءات GitHub وصورة Gitleaks بالبصمات.
- Vitest لاختبارات الوحدة، وPlaywright لاختبار smoke ثنائي اللغة عند عرض 360px.
- اختبار pgTAP وحارس `check-rls` يثبتان عدم وجود جدول `public` بلا RLS، مع probe سلبي داخل
  transaction لإثبات أن الحارس يكتشف المخالفة دون تغيير دائم للمخطط.
- أداة تصدير متغيرات Supabase العامة فقط إلى CI، دون طباعة مفاتيح الخدمة أو حفظها.
- Spike PDF عربي يولّد الشهادة نفسها عبر Chromium و`@react-pdf/renderer`، مع QR وفحص آلي
  للحجم وA4 واستخراج النص وتضمين الخطوط ومسح الرمز ومرجع بصري.
- fixture قرآن من Tanzil Uthmani 1.1 مستوردة آليًا بعد مطابقة SHA-256 للملف ذي 6236 آية.
- ADR-004 الذي يعتمد Chromium/HTML محركًا أساسيًا وVercel + Supabase مستضافًا، مع Chromium
  مخفف داخل Function وخدمة PDF حاوية كخطة تراجع تشغيلية.

### تغيّر

- انتقل مرجع التصميم من `/dev/ui` إلى `/ar/dev/ui` و`/en/dev/ui` دون تكرار المكوّنات.
- ثُبّت `@swc/core` مؤقتًا على 1.15.33 لتجاوز عطل native binding موثق على Windows.
- صار proxy ينعش جلسة Supabase قبل إنشاء استجابة اللغة، وينقل cookies وترويسات منع التخزين،
  ويعالج `/api` دون تحويل لغة.
- عُطّل التسجيل الذاتي والكشف التلقائي للجداول الجديدة، ورُفع حد Node إلى 22 لتوافق SDK.
- صارت جميع عملاء Supabase تستخدم `Database` المولّد، وصار `pnpm db:types` ينسّق الناتج
  تلقائيًا ويحافظ على ثباته بين مرات التشغيل.

### صُحح

- استُبدلت عينتا نص قرآني مكتوبتان يدويًا بنصين عربيين محايدين التزامًا بقاعدة مصدر
  المصحف الموثوق قبل مرحلة الاستيراد.
- أضيف حدّ Suspense حول مبدّل اللغة حتى ينجح prerender مع Cache Components.
- صار تبديل اللغة يحفظ معاملات الاستعلام المكررة، وتحدد روابط اللغة `lang/dir` لقارئات الشاشة.
- صار متغير المفتاح العام يرفض مفاتيح Supabase السرية وlegacy service-role عند خطأ الإعداد.
- صار فحص وصف Data API يقبل حقل OpenAPI الحديث أو Swagger 2.0 الذي يعيده PostgREST المثبّت،
  مع تحقق Zod صريح من وجود أحد الإصدارين.
- أضيف معرّف اختبار ثابت لإصدار Data API حتى يتحقق اختبار smoke من نتيجة Server Component
  نفسها، لا من تحميل الصفحة فقط.
