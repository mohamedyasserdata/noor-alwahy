# ADR-002: أساس نظام التصميم

- **الحالة:** مقبول
- **التاريخ:** 2026-10-17
- **المهمة:** P0-T02

## القرار

- استخدام Tailwind CSS 4 بنمط CSS-first، مع رموز دلالية مرتبطة بألوان الهوية الثمانية.
- امتلاك مكوّنات shadcn/ui داخل المستودع بدل الاعتماد على مكتبة واجهة مغلقة.
- استخدام Cairo المتغير للواجهة وAmiri للنصوص القرآنية والشهادات، بملفات WOFF2 محلية
  محمّلة عبر `next/font/local`.
- فصل ملفات الخطوط العربية واللاتينية ثم وضعهما في سلسلة fallback واحدة؛ لأن حزم الخطوط
  تقسم glyphs بحسب المجموعة اللغوية.
- جميع مساحات الواجهة تعتمد خصائص Tailwind المنطقية وتختبر داخل `/dev/ui` بالاتجاهين.
- تعتمد البوابات الأربع غلافًا واحدًا يحافظ على هوية كل دور؛ قائمة جانبية عند 769px فأكثر
  وشريط سفلي حتى 768px شاملًا حتى يطابق AC-000c حرفيًا.
- الوضع الداكن يستخدم الرموز الدلالية الكحلية نفسها، ويُهيأ بسكربت محلي مبكر قبل hydration
  مع حفظ التفضيل في `localStorage` وتحديث `color-scheme` و`theme-color`.
- تظل الصفحات والأغلفة Server Components؛ يقتصر حد العميل على تحديد رابط التنقل النشط ومبدّل
  السمة، لتقليل JavaScript المرسل للمتصفح.
- قيس التباين للأزواج النصية الفعلية في الوضعين؛ أقل نتيجة 5.14:1، أعلى من WCAG AA للنص
  العادي، واختبرت أهداف اللمس آليًا عند 44px على الأقل.
