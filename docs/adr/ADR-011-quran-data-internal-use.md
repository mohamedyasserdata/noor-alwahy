# ADR-011 — قصر بيانات المصحف على الاستخدام الداخلي

- **الحالة:** معتمد من مالك المشروع
- **التاريخ:** 2026-10-23

## القرار

تُستخدم مجموعة بيانات المصحف المستوردة فقط للتحقق من نطاقات السورة والآية، وحساب الصفحات
والأجزاء، ومتابعة الحفظ والتقييم والتقدم. يمنع عرض نص الآيات في أي واجهة للموقع، بما فيها
لوحات الإدارة والمدرس والطالب وولي الأمر، والتقارير وملفات PDF والشهادات والإشعارات، كما يمنع
إرجاع النص في API أو DTO موجه للمستخدم.

المسموح عرضه: اسم السورة، رقم السورة، رقم الآية، الصفحة، الجزء، ونسب ومؤشرات التقدم المشتقة.
يبقى النص المستورد ثابتًا داخل قاعدة البيانات لأغراض سلامة المصدر فقط، ولا يغير هذا القرار منطق
التقييم أو الحفظ أو المراجعة المتباعدة الحالي.

## الأثر

- لا تعديل حاليًا على المخطط أو الوظائف المنفذة.
- أي واجهة مستقبلية يجب أن تعتمد metadata والمعرفات دون قراءة عمود النص.
- يضاف فحص منع تسريب نص الآيات إلى بوابة الاختبارات المؤجلة قبل الإطلاق.
- كانت موافقة نطاق الاستخدام وحدها لا تستبدل اعتماد P4-T01. لاحقًا، في 2026-10-23، أصدر
  مالك المشروع موافقة نهائية صريحة منفصلة على P4-T01 اعتمادًا على المصدر والبصمات ونتائج
  التحقق الآلي الموثقة، مع الإفصاح عن عدم تنفيذ مطابقة عينات مستقلة.
