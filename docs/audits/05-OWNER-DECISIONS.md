# قرارات مطلوبة من مالك أكاديمية نور الوحي

تاريخ التدقيق: 2026-10-28
لا ينفذ أي خيار في هذا المستند إلا بعد موافقة صريحة. التوصية الافتراضية تحافظ على التصميم والصلاحيات الحالية وتقلل التغيير.

## قرارات لا أنصح بفتحها

- لا AI أو اقتراحات مولدة أو تحليل تلاوة آلي.
- لا عرض نصوص الآيات.
- لا مراسلة مباشرة بين المدرس والأسرة.
- لا إضافة أبناء ذاتيًا؛ الربط إداري فقط.
- لا إظهار تقارير مسودة أو تقييمات غير مقفلة.
- لا تجميع مبالغ بعملات مختلفة.
- لا لوحة قابلة للتخصيص أو مكتبة وسائط أو نظام نقاط/ترتيب لمجرد وجوده لدى منافس.

## نموذج رد مختصر للمالك

يمكن اعتماد القرارات بصيغة: `DEC-001: ب، DEC-002: ب...` مع أي ملاحظة. أي قرار غير مذكور يبقى مؤجلًا ولا يُنفذ.

## ما لا يحتاج قرار منتج

- تصحيح معادلة حضور الطالب لتطابق قاعدة الحالات المعتمدة وواجهة ولي الأمر.
- عدم تسريب التقارير غير المعتمدة والبيانات خارج RLS.
- منع الإرسال المزدوج وحفظ سياق المستخدم عند الخطأ.
- إبقاء حالات الفراغ صادقة دون أرقام أو قنوات مختلقة.
