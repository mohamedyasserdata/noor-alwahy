# مراجعة بوابة المدرس — 2026-10-28

## النطاق

تمت مراجعة جميع مسارات المدرس الحالية، الاستعلامات، Server Actions، سياسات RLS، واختبارات
المتصفح المرتبطة. لم تُضف بيانات وهمية ولم تُفتح صلاحيات جديدة.

## الوظائف المعتمدة والموجودة

| المسار     | الوظيفة الفعلية                                                           | مصدر البيانات/الحماية                                   |
| ---------- | ------------------------------------------------------------------------- | ------------------------------------------------------- |
| اليوم      | الحصة القادمة، حصص اليوم، تسجيل النتيجة، قائمة المراجعة، الانتقال للتقييم | `sessions` وRPC `get_session_join` و`record_attendance` |
| الجدول     | الجدول الأسبوعي بالتوقيت المحلي وتصدير التقويم                            | جدول المواعيد وRLS حسب الدور                            |
| طلابي      | الطلاب المسندون فقط، المسار والمستوى وخطة الحفظ ومؤشرات الالتزام          | `teacher_assignments` و`memorization_plans`             |
| الحضور     | سجل 30 يومًا، النتائج المحفوظة، المتأخر، ونسبة الحضور                     | `sessions` و`attendance` ضمن هوية المدرس                |
| التقييمات  | مسودة محلية، حفظ، قفل، معايير الحفظ والمراجعة والتجويد                    | `session_evaluations` والسياسات المعتمدة                |
| التقارير   | مسودة، مؤشرات محسوبة، اعتماد، مراجعة الإدارة، PDF                         | `reports` وسير الاعتماد الحالي                          |
| التفرغ     | إدارة أوقات تفرغ المدرس                                                   | `teacher_availability`                                  |
| Zoom       | حفظ الرابط المعتمد وإتاحته داخل نافذة الانضمام فقط                        | RPC `get_session_join`                                  |
| المستحقات  | الحصص المحتسبة والكشوف والتصدير                                           | `my_earnings` وRLS                                      |
| الاختبارات | إدخال درجات الطلاب المسندين وفق المعايير                                  | جداول الاختبارات والصلاحيات الحالية                     |
| التنبيهات  | تغييرات الجدول والرابط والإعلانات وتعليمات الإدارة                        | `notifications` مع Realtime وتفضيلات المستخدم           |

## ما تم استكماله أو إصلاحه

- توحيد واجهة المدرس في مساحة عمل كريمية بكحلي وذهبي، Sidebar منظم، Topbar مختصر، بحث
  فعلي في الطلاب، وتنقل هاتف بأربعة مسارات أساسية وقائمة «المزيد».
- إضافة شاشة حضور مستقلة مع سجل ومؤشرات وEmpty State، دون تكرار منطق الحفظ أو تجاوز قفل
  الحضور.
- إبراز الحصة القادمة ونافذة Zoom في الرئيسية، وتوفير انتقال مباشر من الحضور إلى التقييم.
- إظهار عدد حصص اليوم والطلاب والتقييمات والتقارير المطلوبة من البيانات الحقيقية.
- إثراء بطاقة الطالب بالرقم والمسار والمستوى مع بحث بالاسم أو الرقم، مع الإبقاء على خطة الحفظ.
- إصلاح إسقاط روابط تنبيهات المدرس؛ كانت آلية التحقق تقبل روابط الإدارة فقط.
- إضافة Error Boundary خاص بالمدرس يحافظ على البيانات ويعرض إعادة محاولة مفهومة بدل شاشة
  انهيار التطوير.
- توحيد البطاقات والنماذج والجداول على جميع أقسام المدرس دون تعديل تصميم البوابات الأخرى.

## قرارات النطاق

- التعويض والبديل وإعادة الجدولة عمليات إدارية حاليًا، وRPCs الخاصة بها محمية بصلاحية الإدارة؛
  لذلك لم تُعرض للمدرس أزرار لا يملك صلاحيتها.
- لم تُضف مراسلة مباشرة للطالب أو الأسرة. تظل قنوات الأكاديمية والتنبيهات المعتمدة هي وسيلة
  التواصل.
- لا تعرض الواجهة نصوص آيات، ولا تستخدم AI، ولا تنشئ تقديرات أو مؤشرات من بيانات غير معتمدة.

## التحقق

- TypeScript: ناجح.
- ESLint والفحوص المنطقية/منع المراسلة: ناجحة.

  الوضع الداكن، وجميع صفحات المدرس: ناجحة.

- لقطات كل الصفحات: `output/screenshots/teacher/`.

  سير التقرير موجود ومغطى باختبار سابق، ويحتاج اختبار PDF مستقلًا مع Chromium المحلي قبل الدمج.
