# تطبيق المراجع العشرة لبوابة المدرس — 2026-10-28

## النطاق المنفذ

- توحيد Sidebar وTopbar والهوية البصرية للمدرس مع المرجع، مع قائمة أساسية من عشر صفحات.
- إبقاء أدوات التفرغ وZoom والاختبارات داخل مجموعة «المزيد» دون حذفها أو تعطيلها.
- إعادة ضبط عرض الرئيسية والجدول والطلاب والحضور والتقييمات والتقارير والمستحقات لتخطيط أعرض
  وأكثر اختصارًا، مع كروت مؤشرات Pastel وجداول ومسافات متناسقة.
- إضافة صفحة تنبيهات كاملة من جدول `notifications` الحالي، مع القراءة الفردية والجماعية.
- إضافة صفحة ملف شخصي تحفظ الاسم المعروض واللغة والمنطقة الزمنية فقط، مع تحقق IANA وصلاحية
  المدرس وRLS الحالية، وتعرض البريد للقراءة فقط.
- إضافة صفحة «طلبات التغيير» تعرض تغييرات الجدول الفعلية وتشرح قناة الإدارة المعتمدة. لم تُضف
  دالة إرسال وهمية أو صلاحية إعادة جدولة للمدرس لأن Backend الحالي يقصر هذه العمليات على الإدارة.
- لا بيانات وهمية في الواجهة؛ لذلك تعرض بيئة الحسابات الأربعة حالات فارغة عند عدم وجود حصص أو
  كشوف أو تنبيهات فعلية.

## القيد المتبقي

إن أراد المالك لاحقًا أن يرسل المدرس طلب تغيير أو تعويض من داخل النظام، فهذا يتطلب متطلبًا
وظيفيًا مستقلًا: جدول طلبات، حالات اعتماد، RLS، Audit Log، إشعارات للإدارة واختبارات pgTAP.
لم يُنفذ هذا التوسع ضمن تغيير Frontend حتى لا تُمنح صلاحيات غير معتمدة أو يظهر زر غير فعال.
