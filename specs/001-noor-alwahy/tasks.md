# 04 – المهام (Tasks)

**الصيغة:** `- [ ] Pn-Tnn [P] العنوان` — `[P]` = قابلة للتنفيذ بالتوازي مع غيرها في المرحلة · `⇐` التبعيات · **DoD** = ما يثبت الإنجاز.
**قاعدة:** لا تبدأ مرحلة قبل اجتياز **بوابتها** (آخر كل مرحلة). نفّذ مهمة أو مهمتين لكل جلسة مع النموذج.
**حجم المهمة:** S ≤ نصف يوم · M ≈ يوم · L ≈ 2–3 أيام.

### ملاحظة على المسار الحرج
المسار: P0 → P1 → P2 → P3 → P4 → P5 (تشغيل فعلي) ثم P6 → P7 (بيع أونلاين). إن كان البيع أولوية قبل التشغيل (SRC §9)، فقدّم P6 و P7-T01…T05 بعد P2 مع إبقاء الدفتر `subscriptions` المبسّط من P3-T05.
